# 星语小屋 Star-Whisper Cottage

Marketing site for a whole-house homestay in Kundasang, Sabah. Next.js 16, Tailwind CSS v4 and daisyUI, in English and Chinese.

```bash
npm ci
npm run dev        # http://localhost:3000
npm run lint
npm run typecheck
npm run build
```

See [CLAUDE.md](CLAUDE.md) for the architecture, conventions and the environment variables to set on Vercel.
